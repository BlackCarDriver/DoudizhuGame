# 斗地主 · 需求与规则确认版

本文是当前实现的唯一规则口径。后续改动请先改这里，再改代码。

## 1. 房间与座位

- 一桌 3 个座位，按环位 `a → b → c → a` 排列。
- 出牌顺序为**逆时针**：自己 → 下家（屏幕右上方）→ 上家（屏幕左上方）→ 自己。
- 自己永远在屏幕下方；另外两家按相对顺序自动放到左上、右上。
- 换座后视角自动旋转：自己仍在下方，另外两家左右互换。
- 未上座时：
  - 点空位 = 坐该座位；
  - 点「上坐」= 随机坐第一个空位；
  - 满座时按钮显示「观战中」。
- 已上座、未开局：
  - 按钮为「准备 / 取消准备」；
  - 点其他空位 = 换座，并重置准备状态；
  - 已准备时不能换座，需要先取消准备；
  - 提供「离座」。
- 发牌后到结算前禁止换座、禁止上座。
- 三人都在座且都已准备 → 3 秒倒数后自动发牌。
- 倒数期间取消准备 / 离座 / 掉线 → 取消本次开局。
- 一局结束后：座位保留、准备状态清零；所有人重新准备后开下一局。
- 掉线保留座位 20 秒；期间轮到自己时由系统托管。20 秒后仍未回来，座位保留到本局结束，继续托管。
- 主动离座 / 主动离开房间：对局中同样由系统托管打完本局；本局结束后释放座位。
- 对局进行中有人离开导致不足 3 人时，本局继续由托管补位打完，不中止。

## 2. 发牌与叫抢

- 一副 54 张：三人各 17 张，底牌 3 张。
- 发牌后进入**抢地主**：
  - 首叫者随机；
  - 先「叫地主 / 不叫」；
  - 有人叫地主后，另外两家依次「抢地主 / 不抢」；
  - 每抢一次倍数 ×2，最多抢 3 次（×8）；
  - 只要另外两家有人抢，原叫地主者获得一次反抢机会；
  - 无人叫地主 → 重新发牌；连续 3 次流局后随机指定地主（倍数 ×1）。
- 地主确定后亮底牌，底牌加入地主手牌（20 张）。
- 不使用「明牌」，不使用「癞子」，不做「超级加倍」。
- 叫抢每轮 15 秒；超时自动「不叫 / 不抢」。

## 3. 加倍

- 地主确定、亮底牌后，三家各有一次「加倍 / 不加倍」。
- 5 秒读条；超时自动不加倍。
- 地主加倍影响两个农民的输赢（相当于公共倍数再 ×2）。
- 农民加倍只影响自己的输赢。
- 不做超级加倍。

## 4. 出牌

- 地主先出。
- 每手 30 秒；超时：
  - 跟牌：自动「不出」；
  - 首出：系统代出最小单张。
- 托管（掉线 / 主动离开）：
  - 首出：出最小单张；
  - 跟牌：能压则出最小可压牌，否则过。
- 首出不能「不出」。
- 两家连续不出后，最后出牌者重新首出，桌面清空。
- 牌型：
  - 单张、对子、三张、三带一、三带二；
  - 顺子：至少 5 张连续单牌，2 和王不能进；
  - 连对：至少 3 对连续对子，2 和王不能进；
  - 飞机：至少 2 个连续三张，2 和王不能进；
  - 飞机带单 / 飞机带对；
  - 四带二：四张 + 两单、四张 + 一对，或四张 + 两对；
  - 炸弹：四张相同；
  - 王炸：双王。
- 炸弹压非炸弹；王炸压一切；炸弹之间比点数。
- 同类型、同长度才能比较，主牌点大者胜。

## 5. 提示

- 只在自己回合可用。
- 服务端返回所有能压过上一手的候选，按「普通牌型 → 炸弹 → 王炸」排序。
- 首出时第一个候选是最小单张。
- 连续点「提示」在候选之间循环。
- 没有能压的牌时提示「没有能压过上一手的牌」，并高亮「不出」。
- 提示包含炸弹和王炸，但排在普通牌型之后。

## 6. 倍数与积分

- 底分由 `baseScore` 配置（默认 1 分）。
- 公共倍数：

```text
公共倍数 = 抢地主倍数(1/2/4/8)
         × 2^(本局炸弹 + 王炸数量)
         × 春天/反春(×2)
```

- 春天：地主获胜，且两个农民都没有出过牌。
- 反春：农民获胜，且地主只出过第一手牌。
- 个人结算：

```text
单位分 U = 底分 × 公共倍数
农民 i 输赢 = U × 地主加倍(1/2) × 农民 i 自己加倍(1/2)
地主输赢 = 两个农民输赢之和（方向相反）
```

- 每个玩家最多输掉自己当前积分，扣到 0 为止；赢家只拿实际扣掉的部分；未抽水前结算零和，抽水后差额直接销毁。
- 地主余额不足以赔付两个农民时，按两个农民的应得比例分配，余数给最后一个农民。
- 新玩家首次进入发放启动积分（默认 100），无条件到账。
- 最低上桌积分为 `minPointsToSit`（默认 50）；低于门槛不能上桌。
- 余额低于最低上桌积分时，每天可补一次破产救济到最低上桌积分；不要求先打过一局。
- 每个自然日完成至少一局，且余额不低于最低上桌积分，自动发放一次每日活跃奖励（默认 10）。
- 赢家抽水：只对结算后实际正收益抽取；正收益低于 `rakeMinProfit` 不抽，按 `rakePercent` 向上取整，单个赢家单局最多抽 `rakeCap`；抽水直接销毁，输家扣分不变。
- 积分全局按昵称持久化，不使用数据库；存档是 `server/data/players.json`，原子写盘并保留 `.bak`。
- 排行榜按积分降序，同分看胜场，再看负场少；显示前 100 名 + 自己。
- 若本局应输分超过余额，按余额封顶。

## 7. 观众与聊天

- 未上座的玩家自动成为观众。
- 观众可以点座位切换「跟随对象」；同一时刻只显示一家手牌，另外两家只显示牌数。
- 房间配置 `allowSpectatorHands` 控制是否允许观众看牌，默认开启；正式比赛可关闭。
- 观众列表显示在牌桌上方，最多展示 5 个头像，多余的点开浮层查看。
- 所有房间成员都可以在聊天室发言。
- 只有**在座玩家**的聊天/表情会在游戏内头像旁冒泡；观众发言只在聊天室外壳展示，不进入游戏内气泡。
- 游戏内不另做侧边聊天列表。
- 支持聊天室表情透传（`emotion_in_game`），表情以图片气泡展示。
- 头像和头像框通过游戏服务代理，避免跨域/混合内容问题。
